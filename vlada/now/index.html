Present continuous · present perfect continuous · present perfect

Now, Up to Now or Done?

Three tenses, three different questions. The spotlight shows what's happening now. The measuring tape measures how long, from the start up to now. The checklist counts the results: what's done, how many, how much.

🔦 Present continuous am / is / are + -ing What's happening now / these days? We don't say how long. We just look at the picture now.
nowat the momenttodaythis weekthis yearthese days

I'm learning English.
Я учу английский (сейчас, в этот период).

📏 Present perfect continuous have / has + been + -ing How long? Since when? We measure the action from the start up to now.
for…since…How long…?all dayall morningrecently

I've been learning English since September.
Я учу английский с сентября / уже три месяца.

✅ Present perfect have / has + past participle What's the result? How many? Ever? We count what is done up to now. The action itself isn't important, the result is.
how manyhow muchalreadyjustyetever / neverso far

I've read three books this month.
Я прочитала три книги в этом месяце (результат).

⚠️ Non-action verbs (know, like, love, want, have = own) can't take -ing, so they use the present perfect even with how long: We've known each other for ten years. We've been knowing…

Why it feels confusing

In Russian, it's the same tense

«Я учу английский» and «Я учу английский уже три месяца» are both present tense in Russian. In English, the moment you add how long (for / since / уже…), you must switch to the present perfect continuous.

And Russian has a hint for the present perfect too: «я прочитала / сделала / выучила» (a result, it's done) usually means have read / have done / have learned, while «я читаю уже…» is have been reading.

🧪

The test, three questions:
1. Am I counting a result: how many, how much, done or not done, ever? → have + past participle
2. Is there for, since, how long, all day or «уже …»? → have been + -ing
3. Just a picture of now, no length, no result? → am / is / are + -ing

The tricky one

“this year” works with all three

With this year you can use any of the three tenses. The question you're answering is different.

I'm studying a lot this year. 🔦 A picture of this year: what my life is like now. В этом году я много учусь (такой сейчас период).
I've been studying a lot this year. 📏 From January up to today. Often it explains a result now: …so I'm really tired! С начала года и до сегодня я много учусь (вот и устала).
I've passed two exams this year. ✅ The result so far: how many, what's done. В этом году я сдала два экзамена (результат).

💡 I've studied English this year on its own sounds like a finished result («отучилась, всё»). If you're still studying, use I'm studying or I've been studying. Use I've studied with a result: I've studied five grammar topics this year.

⚠️ It's always this year, never in this year. Same with this week, this month, last year, next year: no in.

Watch out

Typical mistakes

I'm learning English for two years.➜I've been learning English for two years.for = how long, so present perfect continuous.
I've studied English in this year.➜I'm studying / I've been studying English this year.No “in” before this year. And for an action that's still going on, use the continuous. The present perfect needs a result: I've studied five topics this year.
I've been reading three books this month.➜I've read three books this month.three books = how many = a result → present perfect.
I have been starting to learn English.➜I started learning English in September.start is one moment (a click ⏯), not a process. A moment in the past = past simple.
How long are you living here?➜How long have you been living here?How long = measuring tape = have been + -ing.
